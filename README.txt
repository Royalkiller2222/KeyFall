# 🎹 KEYFALL — Quick Start

## Step 1 — Install Python (one time only)
Download and install Python from: **https://www.python.org/downloads/**

> ⚠️ During install, check the box that says **"Add Python to PATH"**

---

## Step 2 — Double-click to play
Double-click **`PLAY_KEYFALL.bat`**

That's it. The first launch installs everything automatically (~1 minute).
Every launch after that starts instantly.

---

## Step 3 — Add your songs
Drop any `.mid` or `.midi` files into the **`songs\`** folder.
A built-in demo song plays if the folder is empty.

---

## 🎮 Controls

| Key | Action |
|-----|--------|
| ↑ ↓ | Navigate menus |
| ENTER | Select |
| ESC | Pause / Back |
| F1 | Toggle Easy ↔ Hard mode mid-song |
| F5 | Restart song |
| A S D F G H J... | Play notes (if no MIDI piano) |

---

## 🎯 Modes
- **EASY** 🟢 — Song waits until you play the correct note
- **HARD** 🔴 — Song keeps going, wrong notes penalize your score

---

## ❓ Troubleshooting
- **MIDI piano not detected** → Plug in your piano, then re-launch
- **"Python not found"** → Reinstall Python and check "Add to PATH"
- **Game won't open** → Right-click `PLAY_KEYFALL.bat` → Run as Administrator

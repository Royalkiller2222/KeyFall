  KEYFALL — How to Add Songs
═══════════════════════════════════════════════════════

OPTION A — Difficulty Folders (recommended)
────────────────────────────────────────────
Create a folder for each song inside this songs/ directory.
Inside the folder, place MIDI files named by difficulty:

  songs/
    Moonlight Sonata/
      easy.mid
      medium.mid      (normal.mid also works)
      hard.mid        (expert.mid also works)
      extreme.mid     (insane.mid also works)
      info.txt        ← optional
      cover.png       ← optional, shown in Song Select (cover.jpg works too)

Instead of named files you can also use difficulty subfolders, each holding
one MIDI with any name:

  songs/
    Moonlight Sonata/
      easy/anything.mid
      hard/anything.mid

info.txt format (optional):
  title: Moonlight Sonata
  author: Ludwig van Beethoven

The player can then select the difficulty with ← → in Song Select.


OPTION B — Single MIDI file (quick & easy)
────────────────────────────────────────────
Just drop any .mid or .midi file directly into songs/

  songs/
    my_song.mid

On the next launch (or when you press REFRESH in Song Select) it is moved to
songs/my_song/medium/my_song.mid and shows up as a MEDIUM song. Add easy/hard
versions to that folder later if you like.


ABOUT MIDI FILES
──────────────────────────────────────────────────────
  • All tracks are combined into one piano part. Drum tracks are skipped.
  • The same key played by two tracks at the same moment counts once.
  • Big files are parsed once and cached, so later launches are fast.


MENU MUSIC
──────────────────────────────────────────────────────
Put one MIDI file into songs/_menu_music/ to use it as the main menu music.
That folder does not appear in Song Select.


MIDI FILE SOURCES
──────────────────────────────────────────────────────
  • MuseScore.com       — export any score as MIDI
  • ClassicalMidi.co.uk — classical pieces
  • MidiWorld.com       — large library
  • BitMidi.com         — community uploads
  • Your DAW            — export from GarageBand, FL Studio, etc.

KeyFall - Menu Music Folder
===========================
Drop a single MIDI (.mid) file into this folder and KeyFall will
automatically use it as the main menu music on next launch.

- Only the first .mid file found is used
- This folder is NOT shown in the song selector
- Rename or remove the file to revert to the default synth music
- The file is NOT auto-organized (it stays here as-is)
